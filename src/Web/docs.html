はじめに

本言語のチュートリアルへようこそ。どうぞ、足をお楽にしてお聞きください。 突然ですが、この言語が目指しているものをご存知でしょうか。 ご存知でない方のために簡単にご説明しますと、GENTWOは「英語が読めれば書ける言語」を目指して開発されています。 ですが、この言語の作者である私は、皆さんにこのプログラミング言語にずっと留まってもらおうとは思っていません。それは、この言語の目的ではないからです。 GENTWOは、まだどのプログラミング言語にも触れたことがない人に、プログラミングの考え方をわかりやすく学んでもらい、そこから別の言語へ進んでいくための「踏み台」になることを原則としています。 そのため、GENTWOに留まってもらうことを目的とした機能や仕組みを作ることは、この原則に反するものだと考えています。 とはいえ、GENTWOを使っている間は、少しの間よろしくお願いします。

本言語の思想

1. 人にとって書きやすく。

できるだけ多くの人にとって書きやすくする原則。

2. プログラミングの入り口となる。

初心者にとっても、書きやすくし、プログラミングの考え方を育てる。

3. この言語は踏み台である

前述の通り。

4. 読めばだいたい意味が分かる

以下は構文の例。


SET X TO 10.
DISPLAYS X.

文法

1. テキスト表示

DISPLAYS "HELLO, WORLD!!".

直訳で、「"HELLo, WORLD!!"と表示する。」という意味で、変数Xを表示したい場合は、

DISPLAYS X.

となる。

2. 変数の設定

SET X TO 10.

直訳しなくともわかりやすいであろう。また、型を明示するやり方として、

SET X TO 10 (INT).

などのコードや、

SET X TO 10 (FLOAT).

※整数から浮動小数点数への変換によりデータが失われる可能性はないので、暗黙的に変換しますが警告が出ます。
